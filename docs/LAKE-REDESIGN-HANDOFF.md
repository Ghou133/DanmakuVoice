## 1. 设计原则（每个控件都要过一遍）

1. **做减法。** 先问「普通主播会不会去改它」。不会的：要么删掉、在代码里定死默认值，要么收进「高级」。只有测试人员需要的东西不出现在界面上。
2. **不重复主界面已有的控件。** 播报开关、声音选择、月亮切白天黑夜都已经在主界面上了。
3. **状态不用干巴巴的文字，也不用生硬的按钮。** 用跟内容有语义关系的图形表示，比如服务没开的声音显示成一条虚的平线（没有声音）。能点的地方整行就是按钮，鼠标移上去再出提示。
4. **控件不要照字面画。** 音量不画滑条，也不画由矮到高的竖条（像信号格），而是名字下面的一条「水线」。
5. **删完要重新排版。** 不能留下一大片空白，看起来像页面坏了。剩下的内容要撑满版面。
6. **不要开发者按钮。** 比如「发一条测试」「更新到 OBS」都不要。
7. **这是 Windows 桌面程序，不是手机 App。** 不用大圆角卡片堆叠和胶囊小块；层次靠字号、留白、细线和玻璃材质。
8. **名字直白。** 开关叫「播报」，不叫「朗读」；不用自造的单字分类（例如收/选/改/读/放）。
9. **主界面刻意极简。** 跳过、队列、清空、断线状态都是刻意不放的；也**不要**加「点词或表情就地教读法」这种弹窗（用户明确否决）。
   - 白天黑夜**只靠点太阳/月亮切换**。标题栏上不放主题按钮（主界面现在已经是这样）。现有设置页标题栏里的月亮按钮、初次设置页标题栏里的月亮按钮，随新设计一起去掉。设置变成抽屉以后，标题栏始终只有设置齿轮和窗口按钮。
10. **粉紫渐变只用在「声音」本身。** 播报开关、试听按钮、音量水线、开播按钮。其他地方不用。
11. **不提醒放弃修改，填完就保存。** 不弹「放弃修改」「放弃未完成的填写」这类提醒（2026-10-19 用户定）。填完就自动保存：回车或离开那一项即保存；没填完的草稿在离开时直接放下，不拦导航，也不再问。原地编辑一律用改直播标题那种样子（同一位置、光晕、其余淡出、lilac 下划线和光标），不用浏览器自带的可编辑文本和蓝色选区；保存只改变被改的那几个字，不重绘主界面、不重播动效。

## 3. 主界面

画板：`MainReflect` `MainPeek` `MainDeep` `MainVoice` `MainViewer` `DetailVoice`，以及开播前后 `MainOffAir` `MainTitleEdit` `MainFace` `MainEmpty` `MainEnded`。

### 3.1 倒影（这片湖存在的意义）
- 正在读的那条弹幕留在地平线上方（现有位置和字号）；**水面上是它的倒影**。
- 倒影规则：
  - 以地平线（参考坐标 476/740）为镜像轴，`scaleY(-0.78)`，`transform-origin` 在底边。
  - 遮罩：靠近水面约 62% 不透明，往下渐隐到 0；再叠一层 3px 实、2px 半透明的横纹（`mask-composite: intersect`）。
  - 水纹：SVG `feTurbulence`（`baseFrequency` 约 `0.006 0.1`，慢慢变化）加 `feDisplacementMap`（scale 8），再加 0.6px 模糊。
  - 读到哪个字，倒影也亮到哪个字。
- 两行时文字底部离水面约 16px。只有一行时把文字往下放，让底部同样贴近水面，倒影才对得上。
- 月亮下面已有的月光倒影保留。

### 3.2 历史弹幕：沉在湖里
- **删掉**湖面上现在那几行「沉下去」的历史（`#lake-history` 列表），也删掉单独的历史弹窗（`lake-history-dialog`）。
- 水面左下角只留一句：`128 句沉在湖里 ↓`，数字用 numeral 斜体。
- **鼠标停在水面上**：刚沉下去的最近 3 条浮上来。样式是偏紫、半透明、带轻微水纹（displacement scale 3），越往下越淡。鼠标移开就沉回去。点其中一条打开观众卡片。
- **往下滚**：沉到水下（画板 `MainDeep`）。
  - 天空和山退到顶部窄窄一条，水面变成一条晃动的光线，月亮的方向有几道斜光柱。
  - 左边是历史列表，最新在上，越早越淡，底部渐隐。礼物和醒目留言用 gold。
  - 右边是大号数字：`128 句弹幕沉在湖里` / `今晚 2 小时 14 分` / `52 位朋友说过话`。
  - 顶部一行：`回到水面`、粉色的 `N 句新弹幕`、`正在读 · …`。
  - 往上滚或点「回到水面」浮回去。右下角输入框在水下也保留。
- 用户已接受「看完整历史需要专门往下滚」这个代价。

### 3.3 右下角
只剩两行：
- **声音行**：衬线 18px 的名字，服务名用斜体，后面一个向上的 ⌃。
  - 点名字：打开声音面板。
  - 在这一行上滚轮：调音量。
  - 点名字下面的水线：静音或恢复。水线的点击区域要放大到约 10px 高。

## 4. 设置：浮在湖面上的抽屉

设置**不再是单独一页**，而是从右边滑出、浮在主界面上的玻璃抽屉。主界面留在后面并加一层遮罩，改了声音马上能听到。

### 4.0 抽屉框架
- 位置：标题栏下 8px，右边和底边各留 12px，即 top 48 / right 12 / bottom 12；宽 380，圆角 22。
- 头部：子页有返回键；衬线标题加斜体英文（settings / voices / room / overlay / readings / general / advanced）；右边是关闭。
- 子页在抽屉里推入。宽度可以动画变化：**OBS 连上以后临时变宽到 908**，让预览撑满抽屉高度。
- 所有页面的内容都要撑满高度：底部放说明或版本，不留大块空白。
- 能点的行悬停时不铺色块：行底的分隔线亮成 lilac→pink 的水线，小图形微微发光，箭头右移。
- 滚动条是 4px 细线、没有箭头，放在抽屉右侧留白里，不占内容宽度。

### 4.1 首页（`DrawerHome`）
- 有问题时最上面出现一条金色提示，例如「哔哩哔哩登录已失效 · 重新扫码」；没问题就不显示。
- 四行，每行一个小图形、一个标题、一句状态：
  - 直播间：头像
  - 声音：一小段波形，加默认声音和数量
  - OBS：叠加层缩略图，加连接状态
  - 记住的读法：大号数字
- 四行按抽屉高度平分（每行 76–116px）。通用、高级两行小字和版本号贴在抽屉底部。
- 版本号这一行（首页和通用页底部相同）：
  - 微软商店版由商店自动更新，这一行只显示版本，悬停提示「由 Microsoft Store 自动更新」，不可点。
  - GitHub 压缩包版没有别的更新途径：整行是「检查更新」，结果（正在检查 / 已是最新 / 发现新版本 · 下载新版 / 没查到，再试一次）留在这一行上。

- **礼物合并挪进「高级」。**

- **一个声音都没有**：一条长平线、`还没有声音`、说明、「添加声音」，底部写着不读弹幕也能照常显示。
- **添加声音**：一页完成，不跳转。
  - 顶部一排服务名（豆包 · Fish Audio · GPT-SoVITS · dots.tts），选中的下面一道渐变线，已连上带绿点、服务没开带空心点。默认停在默认声音所属的服务。
  - 没连上的服务在本页原地连接：豆包扫码；Fish Audio 贴 API 密钥（旁边「打开密钥页面」）；本地服务选安装目录后「连接」。连上后原地变成该服务的添加内容，不回到列表。
  - 豆包：整行点一下试听，右侧「添加」一下就加；声音超过 8 个才出现搜索框。
  - Fish Audio：一句说明加「去找声音 ↗」；贴入声音页链接或 ID 后自动查到官方名称，可试听、可改名，「添加」。
  - GPT-SoVITS：列出安装目录里配好对的模型；点一个模型就在它下面展开参考音频、参考文本（文件名里带文字时自动带出）、名字和「添加」。已有声音的模型标「已添加」，点它跳到那个声音的编辑。
  - dots.tts：选一段录音、可选参考文本、名字（默认取文件名），「添加」。
  - 添加豆包后留在本页方便连续添加；其余服务添加后回到声音列表，新声音闪一下。
- 观众专属声音**不在这一页**，在「记住的读法」和观众卡片里。

### 4.4 OBS
画板：`DrawerObsSetup` `DrawerObs` `DrawerObsAdded` `DrawerObsAdvanced`。

- **还没连上**（从没连上过）：普通宽度，整页只做连接。连接被拒绝时只写一行「没能连上：OBS 没打开，或者 WebSocket 服务器没开启」，不重复长串错误。
- **配置过、但 OBS 没开**（连上过，或叠加层已添加，或开了开播联动）：直接是下面「连上」的宽画布，不再显示连接表单。
  - 顶部一行：断开的连线小图形（实点—断线—空心圈）、`OBS 还没打开`、`打开后会自动连上，在这里摆好的位置会同步过去`，右边白色「打开 OBS」。OBS 在别的电脑上时换成「重新连接」。
  - 点「打开 OBS」后连线变成流动的虚线，文字换成「正在打开 OBS…」；连上后原地变成已连接状态。
  - 叠加层照常可以拖动、缩放、双击改刊头。连接设置在「高级」里。
  - 密码错误或 OBS 版本太旧时仍回到连接表单。
  - 上方一个断开的连线小图示、`还没连上 OBS`，再一句说明去哪儿打开 WebSocket。
  - 地址、端口、密码三个下划线输入框；`OBS 程序 · 已自动找到 obs64.exe · 更改`。
  - 「连接」和「先打开 OBS」。
  - 底部一张灰掉的叠加层缩略图，加「连上以后，抽屉会变宽…」。
- **连上、还没添加**：抽屉变宽到 908。
  - 顶部一行 `已连接 OBS · 叠加层还没放进场景`，加醒目的白色 **「添加到 OBS」**（现有 `overlay.obs_add`）。
  - 中间是撑满的实时预览：**直接拖动叠加层摆放，拖右下角的小圆点缩放，靠近边距线会吸附**，OBS 里实时跟着变。
    - 左右、上下分别吸附到各自的边距线（沿边拖会贴住，角落就是两条都贴住）；贴住的那条边出现粉色虚线，松手消失。
    - 上下锚点跟随所在半边（下半屏的叠加层从下往上长）；右侧的角会让内容镜像，所以左右只在贴到左边或右边时才切换。拖动对应现有的 `corner`、`offset_x/offset_y`、`scale`。
  - 底部一行：拖动提示、`OBS 画布 1920 × 1080`、细竖线、「高级 ›」。
  - 2026-10-18 用户改定：预览让出高度，底部一行下面加两条发丝行滑条「暗角深浅」「历史弹幕清晰度」（百分比，numeral 斜体），给“背景一有颜色就看不清字”“历史弹幕看不清”这类反馈；放在 OBS 页本身，不塞进「高级」。
- **已放进场景**：顶部换成 `已放进场景「直播」 · 之后的改动会自动同步到 OBS`，不再有按钮。
- **OBS 高级**：
  - 连接：地址、端口、密码、OBS 程序；
  - 叠加层显示：显示哪些消息、观众名字（不显示 / 仅礼物 / 全部），都用文字点选，不用小块；外加「重复的话合成一条」开关；
  - 开播联动：开播、下播时同步控制 OBS 推流，OBS 没开时先自动启动。
- 定死、不再提供选择的：
  - 样式只保留 **光脊**，一体卡整个删掉；
  - ~~暗角用默认值；~~（2026-10-18 撤回：暗角深浅和历史弹幕清晰度重新可调，见上）
  - 停留时间用默认值。
- 删除：
  - 浏览器来源地址和「复制地址」（想用 OBS 的人都会走 WebSocket）；
  - 「发一条测试」；
  - 「更新到 OBS」；
  - 横向、纵向微调输入框；
  - 所有「实验」标签。

### 4.5 记住的读法（`DrawerReadings` `DrawerReadingsEmpty`）
- 把五种小规则合进一页：观众名字读作（`user_words`）、观众专属声音（bindings）、正文读音（`message_words`）、表情读作（表情别名）。
- 结构：
  - 顶部一条搜索框；
  - 列表按 **观众 / 词 / 表情** 分三组，每组一行小标题、数量和本组自己的「+」（2026-10-19 起空组也显示）。
- 每行固定四列对齐：小标记、原文、细箭头、读法。
  - 标记：观众是彩色小圆点，表情是表情图本身，词不加。
  - 原文用正文字体，读法用衬线字体。
  - 不写「读作」两个字，不加小框。
  - 有专属声音的，读法后面跟一段 lilac 小波形和声音名。
  - 鼠标移上去出现删除。
- 不放底部操作提示。
- ~~添加和编辑都在列表里原地进行：顶部「+」展开一行编辑区（种类单选、「记住 / 取消」）……~~ 2026-10-19 用户否决：编辑区挤在列表里很乱、切种类会沿用原来的观众名字、点进去像换了一页（滑入动效重播、要按两次返回）、退出还弹「放弃未完成的填写」。现在：
  - 这一页就是一页：编辑不是子页面，返回一次就回设置首页，页面不重播动效。
  - 点一行就在这一行原地编辑：同四列、同行高；读法变成带 lilac 线的输入框，观众在读法后面多一个声音选择，词的原文也能改，观众名字和表情名是这一行本身，不改。
  - 组标题上的「+」在本组最上面加一行空的（观众填名字、词填原文、表情填完整名字如 `[doge]`），没有种类切换。
  - 回车或离开这一行即保存；Esc 恢复原样（不关抽屉）；没有保存/取消按钮，也没有放弃提醒。新行没填完就离开页面会被放下；已有行清空读法不算删除，删除仍用行尾的 ×。
  - 不要观众 UID 输入框。
- 空状态：一句标题、一句说明、三条淡掉的示例，下面是三个空组（各自带「+」）。

## 附：状态衔接（2026-10-18 补充）
只在两个状态之间的跳变明显时加衔接，不给所有东西加动画：
- 设置抽屉：关闭时向右滑出并淡出，遮罩同步淡入淡出；子页推入方向跟层级一致（进入从右、返回从左），只是状态变化（例如 OBS 连上）则原地淡入；同一页重新渲染时保持滚动位置。
- 打开设置时主界面的动画暂停而不是清除，云、鸟、水波不会跳回起点；正在出现的字照常出现。
- 潜入 / 浮出历史：新旧画面上下错开交接（视图过渡），标题栏不动。
- 水里的倒影跟着上面的字逐个出现，不再整句先出现。
- 改标题：上方标题、kicker 和倒影一起淡出淡入。
- 人脸验证卡片在右上角原地浮现（之前的居中关键帧会让它斜着飞进来）。
- 开播状态切换、上一场摘要淡入；声音面板、观众卡片、在看的观众、提示条按来时的方式退出。
- 初次设置：换步时只替换抽屉内容，背景的云、鸟、水波继续动；抽屉第一次出现时从右滑入，之后每步的卡片原地淡入。
