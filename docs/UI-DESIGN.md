# 现有界面设计与验收

本文以当前 `crates/desktop/ui` 与 Tauri 窗口代码为准，维护现有设计，不是再次改版的计划。架构入口为 [ARCHITECTURE.md](../ARCHITECTURE.md)，命令契约为 [UI-IPC.md](UI-IPC.md)，实际验证记录只保留在 [PROGRESS.md](../PROGRESS.md)。

## 设计基线

- 产品名“超绝可爱弹幕姬”；文件名、内部标识与数据目录沿用 `DanmakuVoice`。Logo 原图与处理说明见 [图标说明](../crates/desktop/icons/README.md)。账号资料在直播间设置展示，消息头像只使用实际事件提供的资料，缺失时显示文字标识。
- Tauri 2 / 系统 WebView2，本地 HTML、CSS、JavaScript 明确列入 `frontendDist` 并嵌入程序；不嵌入测试、源图、Node.js 或开发服务器。窗口 1040×740，最小 780×580，自绘可拖动标题栏，双击最大化，保留阴影及主题匹配的启动背景。
- 夜幕／晨雾色板，粉—紫—蓝渐变强调色；刊头、聚光文字与数字使用现有系统衬线字体覆盖，`font-synthesis:none`。布局、字体、美术、透明度、阴影、动画时长／曲线与交互反馈均为保留基线。
- 欢迎页之后选择“扫码登录／输入主播 UID”，再选择豆包朗读或只看弹幕，最后汇总并开始接收；欢迎页不请求二维码。匿名 UID 是主播 UID，不是房间号。完成引导后启动只尝试连接已保存的直播间，禁网测试不自动连接。
- 主界面以 LIVE 状态及直播间刊头、单栏弹幕、聚光卡片和控制坞组成。连续同一观众消息合并，间隔至少五分钟插入时间分隔；翻看历史时取消渐隐。聚光进度按文字长度估算，不能当成真实音频进度。
- 控制坞有音色、静音与音量、待播列表、播报开关。浏览服务不改变直播声音；选择音色才保存，试听发起真实合成。选择待播条目调用 `queue.jump`；关闭播报仍接收弹幕。当前主页没有旧版跳过、清空或停止按钮，相关后端命令仍保留。
- 点击弹幕打开观众卡片，可编辑名字读法及专属音色；已有专属声音显示标签。用户名与正文词典分开处理，原始弹幕显示不会被播报替换词改写。
- 设置是整窗页面，分类为直播间、声音、播报内容、音效、通用、数据与关于。保留现有平铺卡片、胶囊、渐变开关与分类移动指示，旧分类 ID 映射保留。输入自动防抖保存，选择器立即保存；切页及关闭设置前收敛编辑，编辑期间无效或失败草稿留在编辑器并提示，不覆盖有效配置。退出会尝试收敛自动编辑并直接清理退出，失败不阻止关闭；账号／导入等显式表单不会自动提交。

## 动画与状态边界

弹幕重排使用 FLIP 位移，聚光行从正文 22 px 连续收回到 15 px，以现有 520 ms 归位；没有旧版脱离副本或正文余晖淡入。`leaveGhost` 用于弹窗、面板及提示条退出，主题通过 View Transitions 扩散；声音渐变圈仅朗读时流动，空状态波纹随连接状态变化。保留当前缓动与轻回弹，不能用降低帧率、删除动画、简化阴影或有损资源处理换取性能。优化放在未变化状态、重复计算、无效重绘和加载过程。

`motionAllowed()` 遵循减少动态效果和现有后台行为。失焦、隐藏、最小化时停止前端轮询与动画，WebView2 内存目标设为 Low；恢复为 Normal 并刷新。Rust 接收、排队和播放不依赖界面可见性。设置打开时不重绘被遮挡的聊天，关闭后补齐安全快照。

凭据、SQLite、网络、规则、队列与设备生命周期由 Rust 拥有。前端只展示快照及编辑草稿，弹幕按文本和经限制的 CDN 表情渲染，不执行消息 HTML。清除数据先确认 WebView2 缓存清理完成，再重置本应用管理的数据；不删除用户指定目录中的未知文件或外部参考音频。

## 验证范围

使用独立 `--data-dir`，必要时加 `--disable-network`；禁网标志拒绝真实网络命令，不制造登录或弹幕。自动化浏览器夹具只用于页面、输入、状态和动画对照，虚构消息必须标明，不能证明真实直播、原生 WebView2 或物理播报。

视觉检查应覆盖两套主题、引导、主页、音色面板、观众卡片、六分类及确认框、键盘／IME、最小窗口和缩放。动画需观察连续帧或录制，静态截图只证明布局。原生首次显示、托盘／恢复、真实扫码、持续播报和外接音频设备分别验收；不能运行的项目记录未验证。

性能对照使用同机、相同 target／profile／feature 和相同负载，包含 WebView2 子进程。`scripts/measure-runtime.ps1` 按 PID 与启动时间累计 CPU 样本增量；两次采样之间完整生灭的子进程仍不可观测，CPU 百分比按单核心表示。WebView2 Runtime 的部署体积独立于程序与必需发行包。
