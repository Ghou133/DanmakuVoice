本文以当前 `crates/desktop/ui` 与 Tauri 窗口代码为准。架构入口见 [ARCHITECTURE.md](../ARCHITECTURE.md)，命令见 [UI-IPC.md](UI-IPC.md)，实际测试和未完成验收只记录在唯一的 [PROGRESS.md](../PROGRESS.md)。

## 2026-10-17 当前设计

实现依据是 [LAKE-REDESIGN-HANDOFF.md](LAKE-REDESIGN-HANDOFF.md) 和用户提供的 `design.html`。已展开直接设计文件中的 45 张画板，对照前 37 张采用方案；最后 8 张已放弃方案不实现。夜间以定稿数值为准，白天从三张日间样例和配色规范推导，仍待用户确认观感。

### 湖面与直播状态

- 默认窗口 1040×740，地平线参考坐标为 476；窗口最小 780×580，跟随 Windows DPI。保留已有太阳/月亮主题切换、月光、远山、水纹和光脊动效；标题栏只有设置和窗口按钮。
- 当前弹幕或直播标题位于水面上方，单行/双行底部对齐水面。水中倒影按 `scaleY(-0.78)` 镜像，叠加渐隐、横纹、位移和模糊；朗读原文和倒影共享由真实播放进度计算的逐字点亮比例。水面波形是状态表现，不宣称 PCM 振幅或逐字音素对齐。
- 水面不常驻历史列表，也没有独立历史弹窗。左下保留消息计数；悬停水面浮出最近三条，离开淡出；点消息进入观众卡片。下滚进入水下历史，上滚或“回到水面”返回；右下输入保持可用。
- 完整历史由当前运行期独立内存归档提供，后台快照仍只携带最近 100 条。水下按游标加载全部消息，新消息到达保持阅读锚点并提示数量；每位观众最近三句和计数来自同一完整归档。同房重连、音频模式重启保留，换房、换账号和退出清空；正文不跨程序重启持久化。
- 右下声音署名可打开 340 px 声音面板，滚轮调节音量，1.5 px 水线显示比例，点击水线静音/恢复。面板里有“播报”总开关、预设列表、悬停试听、管理入口；本地服务未启动时为虚线，点选明确启动，观察就绪后才选择该预设，失败保留原默认。
- 观众卡片宽 350 px，包含头像、实际本场计数/三句、@、称呼读法与试听、跟随默认和波形声音列表。管理权限保持后端核实：1 小时/1 天点击即申请禁言、拉黑二次点击确认、房管开关。B站当前接口只接受整小时，10 分钟项禁用且解释原因。
- 开播准备显示真实房间标题并支持原地改标题和分区，保留输入法安全与失败草稿。等待验证显示二维码并在用户本次明确开播操作内定时重试，受超时、账号、房间与取消约束。空直播间显示 `waiting for the first word…`；下播显示 `WRAPPED` 和本机观察到的摘要。上一场人数/时长未知时省略，不编造历史统计。

### 设置抽屉

- 设置从右侧浮在仍保留的湖面上：top 48、right/bottom 12、宽 380、圆角 22，24 px 模糊玻璃；遮罩只覆盖标题栏下方。OBS 已连接时宽度扩展至 908（小窗口按可用宽度收缩）。子页在同一抽屉中切换，带返回和关闭；输入自动保存失败时保留草稿、重试与丢弃入口。
- 首页四行：直播间、声音、OBS、记住的读法；下面是通用/高级，底部版本。登录失效显示金色重新扫码提示。
- 直播间：账户头像/身份、扫码状态、房间号和换房、当前开播状态、退出账户。扫码与登录状态保持真实后端来源。
- 声音：上方默认声音和可编辑试听句；所有服务声音放在同一细线列表。编辑在行内展开名称、语速/音量水线、设为默认和删除。试听不切换默认；后台刷新和默认选择保留试听文本、输入焦点与滚动位置。被绑定/规则引用的声音不能直接删除，失败事务恢复原默认。一个声音都没有时，空状态底部说明旁有「播放测试音」，不需要任何账号就能确认本机能出声（2026-10-18 用户同意加回，供商店审核和自检；有声音后不显示）。
- 添加声音：四服务列表，随后是可搜索、可试听的目录。Fish 密钥与本地服务路径使用连接版式；密钥只按原有 Windows 加密机制保存，不自动导入。目录试听使用临时预设，添加前不保存预设或改变默认。GPT-SoVITS/dots 的模型和参考音频仍走真实既有接口。
- OBS：未连接时显示连接说明、地址/端口/密码和程序选择；连接后显示真实画布比例和当前叠加层内容，未绑定时显示“添加到 OBS”。拖动位置/右下缩放即时保存并同步，四角吸附有辅助线。按用户确认，双击主标题/副标题原地编辑。高级页保留连接、消息类型、名字显示、重复合并、开播联动；按 2026-10-18 用户决定移除重新生成连接凭据入口。样式固定光脊、暗角 0.6、停留 14 秒；迁移保留位置、比例、标题和令牌。删除来源地址/复制/测试/更新按钮及坐标数字输入。
- 记住的读法：统一观众名字/专属声音、正文词和表情读法，搜索、分组计数、四列列表、添加/删除。表情原文保持展示；只有设置过读法的表情才参与播报，官方表情过滤不再是用户开关。
- 通用：中英文、开机启动、导出与恢复。恢复先备份当前数据再事务替换配置；登录和服务密钥不导出/导入，声音文件另行保留。
- 高级：一次展开一项的消息门槛、可编辑字段块模板、关键词音效；礼物合并和恢复默认。模板支持输入法、粘贴、多行及字段插入/恢复。音效从本机选取，用过的保留列表，无独立素材管理页。
- 不再展示主题、缩放、输出设备、重做引导、预览规则或实验标签。主题由天空天体切换，音频/缩放跟随 Windows 默认。

# 现有界面设计与验收

本文以当前 `crates/desktop/ui` 与 Tauri 窗口代码为准。架构入口为 [ARCHITECTURE.md](../ARCHITECTURE.md)，命令契约为 [UI-IPC.md](UI-IPC.md)，实际验证记录只保留在 [PROGRESS.md](../PROGRESS.md)。

## 2026-10-06 水月主界面

当前主页直接对照用户提供的 `Lake.dc.html` 与日间观众包装页实现。2026-10-06 第一轮近似实现已由用户指出不一致，随后重新以原 HTML 自身 DC 运行时的实际渲染、CSS 关键帧及交互为基准逐项修正；第一轮截图不作为原稿一致性的证据。产品继续使用 Rust 引擎、真实状态和既有 IPC。主画面加载本地 `lake-scene.mjs`、`lake.css` 和 `lake-drawers.css`，这些文件均列入 Tauri `frontendDist`。

- 默认 1040×740 窗口水平线位于 476px；天空、两层远山、湖面随窗口适配。夜间显示环形山月亮、星星、流星、月光路径和涟漪；日间为蓝紫藕粉天空、奶油太阳、云、小鸟和暖金光路。水平线波形随实际朗读状态变化，关闭播报时为平线；不是 PCM 振幅测量。
- 左上保留原稿的星期刊头、本机日期时间和「用户名的直播间」，不以直播主题替换用户名；人数为零时隐藏人数入口。右上标题栏只保留设置（2026-10-14 起日夜切换改由天空中的太阳/月亮完成）；未启用开播台时没有开播或下播按钮。启用后右侧保留状态、计时和直播操作；弹幕接收与开播状态继续独立。
- 最新一句为天空中的大号衬线文字，按字素逐字浮现；前四句从新到旧沉入湖面，原消息节点直接迁移。全部弹幕抽屉展示引擎保留的最近 100 条本机接收记录，未新增持久化弹幕档案。长弹幕的完整正文可在抽屉查看。保留原始用户名、表情及文字，不使用演示观众或演示弹幕填充产品。
- 没有弹幕时，天空提示随接收连接状态及时刷新；成功连接显示 `the lake is still.`，重连、登录失效和断开分别显示实际状态及相应操作，不等待第一句弹幕才更新。接收状态变化不重建已有弹幕或重新播放逐字动画，也不扰动准备画面的直播标题。
- 2026-10-14 按用户反馈去掉重复的声音入口。点击太阳/月亮切换日夜（悬停提示 `夜间 · evening`／`日间 · afternoon`）：新主题从它的位置扩散，旧的那颗下沉淡出、另一颗随后升起；减少动态效果时直接切换。保存外观要等过渡截下旧画面之后才发出，保存返回的快照不会把动画跳过。日间刊头为“星期 afternoon”，夜间为“星期 evening”。设置页标题栏的日夜按钮保留，太阳/月亮只在由它触发的过渡中单独命名，不会盖到设置弹窗上。左侧那圈装饰涟漪从“earlier tonight →”周围移到开阔水面（原稿坐标 470, 560），避免像按钮边框。
- 底栏按原稿只显示声音署名与发送输入行。声音署名是声音玻璃浮层的唯一入口，浮层在署名上方打开，整合实际声音预设、朗读开关和 0–100 主音量。发送独立于直播模式，登录与网络可用时允许发送，账号身份、目标房间与平台权限由后端核实。
- 主界面有意保持简洁（2026-10-14 用户再次确认）：不显示跳过、待读列表或清空，也不在已有弹幕时显示断线/重连提示（空天空时的连接状态提示保留）。相关后端命令仍保留；不要在主界面补回这些入口。
- 自有直播标题和分区直接在天空编辑：淡光晕、其他内容淡出、玻璃分区列表，只留保存；Enter 保存，中文输入法确认不会误提交，Esc/背景放弃未保存内容，保存失败保留草稿。主界面不显示叠加层标题编辑；OBS 设置的“刊头文字”恢复主标题输入，保留旧值，支持 1–24 字并自动保存、同步预览。
- 观众卡片保留右侧 350 px 玻璃抽屉、居中头像和名字、`said N tonight`、@ TA／试听称呼及最近三句。根据 2026-10-06 最新反馈只重排下方管理区；音色选择保留原来的 30 px 胶囊按钮、自然换行、6 px 间距和粉紫渐变选中态，不改为两列卡片。声音保存与后台刷新保留卡片滚动位置和焦点。直播间管理使用同一个淡玻璃分组，禁言按钮移到标题行右侧、时长条位于其下，拉黑和房管按统一左右轴排列，以细线分隔。默认禁言 1 小时；拉黑仍需原按钮内二次确认，成功禁言提示保留撤销并再次核实权限及账号/房间。管理区是最新授权的设计变化，不再作为原稿逐像素一致项；原音色选择、上部与主场景继续对照原稿。
- 人数区域悬停立即打开观众名单，离开入口 350 ms 后收起；进入面板取消延迟，离开未固定的面板立即收起。点击人数固定名单，背景/Esc 收起；点击观众转为卡片，关闭卡片回到主画面。全部弹幕抽屉从新到旧显示时间、原文、头像和名字。名单、全部弹幕及观众卡片均无 ×，支持背景/Esc；卡片保留内部滚动和键盘焦点循环。
- 准备、安静、正在朗读、人脸验证和下播通过真实状态切换，首页准备标题移除 tonight’s title 标签。人脸验证只保留继续开播，背景取消；下播显示“今晚辛苦啦”并可回到准备。上一场摘要由 Rust/SQLite 按账号和自己的直播间保存，重启后恢复；统计仅包含本程序实际接收的消息及可确认的时长。没有上一场时湖面直接留空，未知时长省略，不显示“暂无记录”或虚构的零时长。
- 表情浮层先显示登录账号的评论个人表情包，再显示直播房间包，各来源内部保持返回顺序。个人包读取 `packages[].text/url/emote[]`，直播包读取 `pkg_name/current_cover/emoticons`；名称仅保留在原始数据和无障碍标签，界面只显示包封面与表情图片，没有标题、名称、数量、悬停文字或分页。封面缺失时选用包内首张合法图片，再缺失则显示无文字的缺图图形。顶部封面条横向滚动，选中包全部表情以五列连续纵向滚动；同包刷新保留滚动位置，主动切包回到顶部。浮层复用水月的日夜玻璃底色、边框、阴影与动效，表情没有单独框线卡片，悬停轻微浮起。所有表情点击即单独发送，保持输入框草稿和选区；个人条目发送前重新读取当前账号资料，按原始 `[包名_表情]` 独立提交普通消息，直播独立表情保留真实 token 与锁定权限。某来源失败在输入状态明确提示，面板保留无文字提示图形，登录过期清空缓存。切换账号或接收上下文立即清空旧包和选包；异步旧响应不能恢复旧账号或解除新请求的忙状态。发送目标仍为账号自己的直播间。

## 保留功能与早期设计记录

- 产品名“超绝可爱弹幕姬”；文件名、内部标识与数据目录沿用 `DanmakuVoice`。Logo 原图与处理说明见 [图标说明](../crates/desktop/icons/README.md)。账号资料在直播间设置展示，消息头像只使用实际事件提供的资料，缺失时显示文字标识。
- Tauri 2 / 系统 WebView2，本地 HTML、CSS、JavaScript 明确列入 `frontendDist` 并嵌入程序；不嵌入测试、源图、Node.js 或开发服务器。窗口 1040×740，最小 780×580，自绘可拖动标题栏，双击最大化，保留阴影及主题匹配的启动背景。
- 夜幕／晨雾色板，粉—紫—蓝渐变强调色；刊头、聚光文字使用内置的 DanmakuVoice Serif SC（原稿同版本 Noto Serif SC 2.003-H1 子集，GB2312 全部汉字 + 界面用字，保留可变字库插值，500/700/900 三个精确字重声明，400 按字体匹配选择 500），子集外的字逐字回退到系统衬线字体；数字使用 Instrument Serif，`font-synthesis:none`。字形证据独立比较官方原字体与生产子集，不再给原稿注入生产字库作为字体证明。
- 欢迎页之后扫码登录哔哩哔哩，再选择豆包朗读或只看弹幕，最后汇总并开始接收；欢迎页不请求二维码。已移除匿名模式、主播 UID 选择及登录失败后的匿名入口。完成引导且存在登录凭据后才尝试连接保存的直播间；旧匿名配置返回扫码登录，禁网测试不自动连接。

## 动画与状态边界

水月主画面按原 HTML 的动画执行：逐字 160 ms 延迟、900 ms 浮现；上一句以同一 DOM 节点 900 ms 沉入湖面，再以 6 s 摆动；安静波形 6 s、朗读波形 1.1 s 与每根柱的原稿负延迟、关朗读平线；星光 6 s、流星 17 s、云 140 s、鸟 80 s／振翅 650 ms、雾 46 s、光路 3 s、涟漪 9 s。玻璃浮层 300 ms、抽屉 450 ms、天空编辑 500 ms、标题聚焦光线 600 ms、人脸面板 450 ms、提示条 300 ms 并在成功提示 3600 ms 后直接收起；背景关闭浮层/抽屉按原稿立即收起。主题使用 View Transitions 的 950 ms 圆形扩散，半径到 160vmax。

旧版弹幕 FLIP、520 ms 聚光归位及 `leaveGhost` 辅助能力仅保留在仍使用它们的其他界面/后端入口，不作为当前水月动画说明。保留原稿缓动、轻回弹、完整阴影和关键帧；优化放在未变化状态、重复计算、无效重绘和加载过程。

`motionAllowed()` 遵循减少动态效果和现有后台行为。失焦、隐藏、最小化时停止前端轮询与动画，WebView2 内存目标设为 Low；恢复为 Normal 并刷新。Rust 接收、排队和播放不依赖界面可见性。设置打开时不重绘被遮挡的聊天，关闭后补齐安全快照。

主湖面的弹幕首次在前台绘制后，按原生窗口会话、账号与接收房间保存有界 SHA-256 展示键（8 个上下文，每个 512 项）；sessionStorage 不存正文、用户名或凭据。失焦回来、语言重建或页面重载时，已展示句直接恢复完整形态，后台尚未绘制的新句仍首次逐字浮现。播报完成的同一节点不会重复插入；只有被新句替代的原句触发同节点沉水，恢复的历史没有入口重演。准备画面的直播标题保持原首次动效。

凭据、SQLite、网络、规则、队列与设备生命周期由 Rust 拥有。前端只展示快照及编辑草稿，弹幕按文本和经限制的 CDN 表情渲染，不执行消息 HTML。清除数据先确认 WebView2 缓存清理完成，再重置本应用管理的数据；不删除用户指定目录中的未知文件或外部参考音频。

## 验证范围

使用独立 `--data-dir`，必要时加 `--disable-network`；禁网标志拒绝真实网络命令，不制造登录或弹幕。自动化浏览器夹具只用于页面、输入、状态和动画对照，虚构消息必须标明，不能证明真实直播、原生 WebView2 或物理播报。

视觉检查应覆盖两套主题、引导、主页、音色面板、观众卡片、七个设置分类及确认框、键盘／IME、最小窗口和缩放。动画需观察连续帧或录制，静态截图只证明布局。原生首次显示、托盘／恢复、真实扫码、持续播报和外接音频设备分别验收；不能运行的项目记录未验证。

性能对照使用同机、相同 target／profile／feature 和相同负载，包含 WebView2 子进程。`scripts/measure-runtime.ps1` 按 PID 与启动时间累计 CPU 样本增量；两次采样之间完整生灭的子进程仍不可观测，CPU 百分比按单核心表示。WebView2 Runtime 的部署体积独立于程序与必需发行包。
